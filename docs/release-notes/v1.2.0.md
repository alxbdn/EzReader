## What's new in 1.2.0

### Improvements
- **Add pictures from the side panel:** "Add a file" at the end of the page list now takes PDFs and pictures (PNG, JPEG, WebP, GIF, BMP). You can pick several files at once: each picture becomes a page.
- **Better tables in PDF to Excel:** each table gets its own columns, so amounts land in the right cells instead of spreading over empty columns. A description that wraps onto a second line stays in its row. Amounts with a currency sign or in brackets, like "1 250,00 €" or "(12.00)", become real numbers.
- **Simpler Export & convert:** the "Images to PDF" tab and menu entry are gone. To make a PDF from pictures, open or drop them in EzReader.

### Fixes
- **macOS on Intel:** EzReader no longer opens on a black window on Macs running older versions of macOS.
- **Quick look with Space (Windows):** it keeps working after an update, without turning it back on in Settings.

The macOS version is published on the [Homebrew tap's releases](https://github.com/alxbdn/homebrew-ezreader/releases) shortly after this release. `brew upgrade --cask ezreader` picks it up.
