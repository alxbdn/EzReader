## What's new in 1.1.10

### Improvements
- **One "More tools" menu in the toolbar:** Export, Compress, Protect with a password, Document info and Present now sit together in a single ⋯ menu next to search. The toolbar stays on one line on narrower windows instead of wrapping onto a second row.

The macOS version is published on the [Homebrew tap's releases](https://github.com/alxbdn/homebrew-ezreader/releases) shortly after this release. `brew upgrade --cask ezreader` picks it up.
