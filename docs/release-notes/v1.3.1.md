## What's new in 1.3.1

### New
- **Read EPUB books:** open an `.epub` like a PDF, and save it as a PDF with its chapters as bookmarks.
- **Edit text in the original font:** clicking a line to replace it now starts in the font it was written with (the installed font when there is one, otherwise the closest one), in bold or italic as needed, at the same size and colour.
- **Replaced text is really gone:** like a redaction, saving removes the original words from the file instead of only covering them.
- **Fonts in Document info:** the info panel lists the fonts the PDF uses, one per line.
- **Ten more fonts** for text boxes: Aptos, Calibri Light, Arial Narrow, Century Schoolbook, Bookman Old Style, Lucida Sans Unicode, Microsoft Sans Serif, Myriad Pro, Roboto and Open Sans.
- **Light and dark switch** on the toolbar.

### Improvements
- Export, Compress, Protect, Info and Present are back on the toolbar; they fold into the "…" menu only when the window is too narrow.
- Hand and select read as one toggle.
- In the light theme, lowering the brightness dims the whole window, not just the page.
- Scanned books in JPEG 2000 or JBIG2, PDFs with Asian text in non-embedded fonts, and print-ready CMYK files now display correctly.

### Fixes
- Clicking the file name in the title bar renames the file again.
- Editing replaced text no longer shows the old and new text on top of each other, and a bigger font no longer spills over the lines below.
- The brightness slider no longer jumps when it opens.

The macOS version is published on the [Homebrew tap's releases](https://github.com/alxbdn/homebrew-ezreader/releases) shortly after this release. `brew upgrade --cask ezreader` picks it up.
