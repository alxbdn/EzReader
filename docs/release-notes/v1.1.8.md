## What's new in 1.1.8

### New
- **Quick look in File Explorer (Windows):** select a PDF and press Space to preview it in a window over Explorer. Space or Esc closes it, and the arrow keys move to the next or previous file.
- **PDF thumbnails and preview pane in File Explorer (Windows):** PDFs now show their first page as a thumbnail, and the Explorer preview pane displays them.
- **Drag pages into a new tab:** drag pages out of the Pages panel and drop them inside the window to open them as a new document in a new tab. Dropping outside the window still opens a new window.
- **Smooth mouse-wheel scrolling on Linux:** wheel notches now glide instead of jumping. Touchpads keep native scrolling. Thanks to Stiven for the original work.

### Improvements
- **PDFs open straight in the viewer:** double-clicking a PDF no longer shows the launcher first.
- **Faster zoom:** Ctrl+wheel and pinch zoom redraw pages sooner and stay fluid.
- **Smoother launcher on integrated graphics:** the dot grid and ripple animation no longer stutter.
- **Slideshow starts cleanly:** the first page appears once the window is full screen, without a flicker.
- **Default app setup on Windows:** on Windows 10 the button opens the .pdf app picker directly, and on Windows 11 it opens Settings on EzReader's default-apps page.
- **Highlight popover:** right-clicking a highlight now shows Copy inside its popover instead of a second menu on top of it.

### Fixes
- Page thumbnails no longer go blank after opening another PDF.

### Under the hood
- More automated tests (Rust, interface flows, regressions) and a check that the build is reproducible.
- Repository layout cleanup.
- The Windows MSIX package is attached to the release again.
- The macOS disk image is now built and published by the Homebrew tap, on [its releases page](https://github.com/alxbdn/homebrew-ezreader/releases), shortly after each release. `brew upgrade --cask ezreader` picks it up as before.
