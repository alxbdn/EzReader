## What's new in 1.3.0

### Improvements
- **Updates install themselves:** when a new version is out, EzReader downloads it in the background at launch and installs it when you close the app, so the next launch runs it. No click needed. "Restart to update" next to the version applies it right away. This works for the Windows installer, the portable files, Homebrew and the macOS disk image. A `.deb` still asks for your password, so it keeps the update button.
- **Microsoft Store version updates without opening the Store:** EzReader asks the Store for the newest version itself and installs it when you close the app.
- **Copy, paste and duplicate annotations:** Ctrl/Cmd+C copies the selected note, shape, text box, stamp, signature or picture, and Ctrl/Cmd+V pastes it on the page in view. Ctrl/Cmd+D (Edit › Duplicate) duplicates it in place. Each paste is one undo step.

The macOS version is published on the [Homebrew tap's releases](https://github.com/alxbdn/homebrew-ezreader/releases) shortly after this release. `brew upgrade --cask ezreader` picks it up.
