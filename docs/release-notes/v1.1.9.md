## What's new in 1.1.9

### Improvements
- **Quick look opens on the first Space press (Windows):** selecting a PDF in File Explorer and pressing Space now opens the preview straight away, centered on the screen. Pressing Space again closes it.
- **Chapters start folded:** in the document structure panel, chapters with sub-entries start folded so long outlines stay readable. To keep them expanded, turn on "Expand chapters in document structure" in Settings > Interface.
- **Custom colors:** the rainbow swatch now opens a color picker inside EzReader, with keyboard support, instead of the system color dialog.

### Fixes
- Highlighted text stays crisp and dark at any highlighter opacity instead of being covered by the color.

### Under the hood
- Repository cleanup: internal working files are no longer kept in the public repository.

The macOS version is published on the [Homebrew tap's releases](https://github.com/alxbdn/homebrew-ezreader/releases) shortly after this release. `brew upgrade --cask ezreader` picks it up.
