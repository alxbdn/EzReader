# Spec Kit (archived)

EzReader started from the [Spec Kit](https://github.com/github/spec-kit) template, which writes each feature as a spec, then a plan and a task list, before coding it. Work now goes straight into pull requests, so the tool is kept here for reference only:

- `specify/`: Spec Kit's scripts, templates and project constitution (was `.specify/` at the root).
- `commands/`: the `/speckit.*` commands for Claude Code (was `.claude/commands/`).

The specs written with it are in [`docs/specs/`](../specs/).
